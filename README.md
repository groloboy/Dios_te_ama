# Dios te ama

Libro digital de esperanza, fe y paz. 18 páginas con animación de paso de página.

Un único archivo HTML autocontenido, sin dependencias externas: funciona sin
conexión y se puede abrir directamente desde el disco.

- `index.html` — el libro completo (HTML + CSS + JS en un solo archivo)
- `dios-te-ama.html` — copia idéntica, con nombre explícito para descargar

Publicado con GitHub Pages.
